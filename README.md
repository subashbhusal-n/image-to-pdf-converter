## ✨ Overview

**Image to PDF Converter** is a Python-based tool that allows you to
convert one or multiple images into a single PDF document.

It is designed as a simple, practical project for learning how Python
can be used for image processing, file handling, and automation.

Instead of manually converting images one by one, this program makes
the process faster and easier.

---

## 🚀 Features

- 🖼️ Convert images into PDF
- 📑 Combine multiple images into one PDF
- 📂 Supports common image formats
- ⚡ Fast and lightweight
- 🐍 Built entirely with Python
- 💻 Easy to use
- 🔧 Simple and beginner-friendly code
- 📄 Generate organized PDF documents
